# Jiangnan Architect Agent 开发路线图

项目聚焦江南单体建筑、园林构件与模块组合，不负责整座城镇的自动规划。目标游戏版本固定为 Minecraft Java 1.21.5，DataVersion 4325。默认只生成独立工程文件，不直接改写已有 Minecraft 世界。

## 九个开发阶段

### Phase 0 — 项目初始化

建立独立 Git 仓库、Python 环境、项目配置、pytest 和 CI。支持读取/保存工程配置并运行首条 CLI 命令。**本地实现完成；GitHub 远端尚未连接。**

### Phase 1 — Minecraft 方块数据引擎

建立 `Block`、`BlockState`、`VoxelModel`、`BoundingBox`；统一 X/Y/Z；按 Sponge 官方 Schematic v3 规范导出和回读 `.schem`。方块状态需保留楼梯、半砖、门、栏杆等属性。**实现和自动化验收完成；Minecraft/WorldEdit 实机放置待验。**

### Phase 2 — 参数化古建筑构件引擎

实现柱、梁、墙、门窗、台基、屋顶、檐口、回廊等生成器；开间、进深、柱高、屋顶坡度、出檐和材料均可调。验证三开间、五开间及参数变化后的结构连接。

### Phase 3 — 模块化组合系统

组合门楼、厅堂、厢房、亭子、回廊等模块；定义连接锚点、占地边界、方向和连接规则。支持平移、旋转、镜像、连接、拆分、替换，并检测碰撞、门洞错位、檐口冲突和接缝高差。

### Phase 4 — 工程保存与局部修改系统

建立 JiangnanProject 工程格式、对象 ID、模块参数和连接关系、变更记录、版本快照与撤销；局部修改尽量不影响其他模块。

### Phase 5 — 接入 GPT-6 Agent

在模块引擎稳定后研究 OpenAI Agents SDK。第一版使用单一总控 Agent；模型输出结构化决策和工具参数，由本地工具生成方块。

### Phase 6 — 三维预览与视觉审核

先手动验证 `.schem` 到 Mine2Blend/Blender 的导入，再探索自动导入与后台渲染。提供俯视、正面、侧面、透视预览和修改对比。

### Phase 7 — 江南古建筑知识库与专业构件

建立带文献出处和适用地域的知识库，扩展苏式民居、徽派、屋顶、花窗、马头墙、石桥、亭榭、假山、池塘等；参考图中的无法确认尺寸需标为估算。

### Phase 8 — 本地设计工作台与完整验收

提供本地 CLI 对话工作台，后续可增强模块拖拽界面。完成“描述→生成→预览→修改→组合→保存→导出→游戏内放置”闭环。

## 五个里程碑

- **M1 方块生成闭环**：Phase 0–1；导出真实可用的 `.schem`。
- **M2 模块化设计闭环**：Phase 2–4；生成、组合、编辑和保存模块。
- **M3 AI 设计闭环**：Phase 5；自然语言控制建筑生成与修改。
- **M4 视觉审核闭环**：Phase 6；自动预览并比较修改。
- **M5 完整个人工作台**：Phase 7–8；知识库、扩展构件和长期使用。

## Agent 工具组

| 工具组 | 典型工具 | 职责 |
| --- | --- | --- |
| 模块管理 | `list_modules`, `create_module`, `get_module` | 查找、创建、读取模块 |
| 建筑设计 | `generate_building`, `set_parameters` | 创建和调整建筑 |
| 组合装配 | `connect_modules`, `rotate_module`, `replace_module` | 对齐、组合、替换 |
| 质量检查 | `validate_assembly`, `inspect_changes` | 检查结构、冲突和变更 |
| 工程交付 | `save_project`, `render_preview`, `export_schematic` | 保存、渲染、导出 |

## 质量要求

1. **可重复生成**：相同输入、模块版本和随机种子产生相同方块结果。
2. **独立可编辑**：每个模块有固定 ID，可独立更改或替换。
3. **方块状态正确**：旋转后门、楼梯、屋脊等状态正确。
4. **可回退**：工程变更有历史并可恢复。
5. **输出可靠**：`.schem` 可独立回读校验，并通过真实游戏放置检查。
6. **原始世界安全**：不直接写入已有 Minecraft 世界；施工先生成独立文件。

## 固定质量案例

三开间厅堂、五开间厅堂、转角回廊、双侧厢房组合、旋转 90° 的屋顶、带台阶的园林亭。建筑检查还要覆盖门窗可用、通行空间、屋顶缺口和模块接缝。

## 权限边界

生成与预览可以自动运行。覆盖已批准模块、删除文件、修改 Minecraft 正式世界需要人工确认。
