# Phase 4 工程保存与局部修改设计

## 意图

让 Phase 3 的模块组合成为可持续编辑的工程。用户保存并重新打开 `.jap.json` 后，仍能取得相同模块、参数、连接关系和方块状态；修改一个模块时记录版本与方块差异，并可撤销、重做。

## 目标

- 扩展 `JiangnanProject`，在一个可读 JSON 文件中保存完整 `Assembly`、模块稳定 ID、生成参数、变换步骤、锚点、净空区和连接关系。
- 保留 Phase 0–3 已有工程文件和 API；旧格式读入后迁移到当前格式。
- 为每次模块替换或参数重生成建立完整状态快照、父版本、编辑说明、受影响模块 ID 和逐方块差异。
- 支持保存/重开、撤销、重做；撤销后产生新编辑时丢弃原来的重做分支。
- 支持按模块 ID 更新厅堂或直廊参数，只重生成该模块；重放其放置变换，保留其余模块的 ID、对象和方块数据。
- 提供只读历史查看，并保持原始 Minecraft 世界不受影响。

## 非目标

- 不实现多用户并发合并、数据库、压缩/增量快照或云同步。
- 不实现任意 Python 生成器插件；首版可重生成 Phase 2 的厅堂和直廊。
- 不自动修复因尺寸变化导致的锚点错位或模块冲突；保留连接并由 Phase 3 验证器报告。
- 不直接写入 Minecraft 存档，不实现 AI、图形界面或 Blender 预览。

## 方案比较与选择

1. **完整工程 JSON + 每版完整 Assembly 快照与方块差异（采用）**：复用现有 `.jap.json`，透明、易复制、无需新依赖；代价是文件随历史增长。
2. **SQLite 事件日志与定期快照**：适合大工程和长历史，但增加迁移、调试和依赖复杂度，当前规模不需要。
3. **工程元数据 JSON + 每模块单独 `.schem`**：方块文件可分开管理，但会丢失完整锚点、参数、变换和连接语义，局部重建更难。

## 设计

- 工程格式升级到版本 2；读取版本 1 并保留其工程名、Minecraft 版本、DataVersion、设置和旧 `modules` 扩展记录。版本 1 项目得到空 Assembly 的初始快照，保存时写为版本 2。
- `Module` 增加 JSON 值组成的 `parameters` 和有序 `transform_steps`。厅堂/直廊适配器填入生成参数；平移、旋转、镜像函数同时记录变换步骤，使参数重生成能在原放置坐标系复现。
- Assembly 序列化包含模块、稀疏坐标/方块状态、锚点、净空区和连接。集合顺序按稳定键输出；方块状态保留完整属性。
- `ProjectRevision` 保存连续整数 ID、父版本、UTC 时间、说明、模块 ID、精确 `BlockChange` 列表和不可变 JSON Assembly 快照。当前工程状态由历史游标指向；新编辑会裁掉游标之后的重做分支。
- `ProjectEditor.regenerate_module()` 合并该模块的参数变更，只支持 `hall` 和 `corridor`；从生成器创建新模块，再按保存顺序重放变换步骤。替换保留模块 ID 和连接记录；其他模块对象与方块不变。锚点/冲突检查继续由现有 `validate_assembly()` 承担。
- 工程文件沿用同目录临时文件、flush/fsync 和原子替换保存方式；JSON 不允许 NaN/Infinity。
- CLI 增加 `history`、`undo`、`redo`。`generate` 来源规则固定为：Assembly 非空时优先验证并导出 Assembly，即使 `settings.building` 存在也不参与；Assembly 校验/渲染失败时报错且不回退；Assembly 为空时使用旧 `settings.building`。未来可增加 `source="auto" | "assembly" | "legacy"`，`auto` 保持当前规则；此参数不属于 Phase 4。不得写入 Minecraft 世界。

## 验收

- 版本 2 工程保存、关闭、重新加载后，完整 Assembly、参数和连接关系相等；版本 1 工程可读并迁移。
- 楼梯、门等带状态方块以及负坐标、空模块、锚点和净空区可无损往返。
- 修改厅堂/直廊参数只替换目标模块，原参数、变换顺序、锚点和状态随生成器重建；其他模块的模型映射不变。
- 历史记录准确列出新增、删除和状态变化方块；保存重开后撤销/重做仍可用；撤销后新编辑不再能重做旧分支。
- CLI 可查看历史并执行持久化撤销/重做；`generate` 按固定的 Assembly 优先、空 Assembly 使用旧设置、失败不回退规则工作；全套 pytest 通过，Minecraft/WorldEdit 实机验收仍单独标记。
