# Phase 2 参数化构件引擎设计

## 意图

在现有稀疏 `VoxelModel` 与 Sponge v3 导出能力上，增加可复用的江南建筑构件生成器和参数化厅堂装配器。改变开间、进深、柱高、屋顶起坡和出檐参数时，构件位置按同一套坐标规则重新计算，并保持结果可重复。

## 目标

- 提供柱、梁、墙及开口、台基、门、窗、檐口和双坡屋顶的独立生成函数。
- 以构件函数组合直廊与厅堂；至少验证三开间、五开间和参数变更。
- 支持配置材料方块状态；门的上下半部、门朝向、屋面楼梯朝向及木梁轴向均可序列化。
- 让 `jiangnan generate` 能从工程 JSON 生成厅堂 `.schem`，继续使用已有 Sponge v3 写入器。
- 碰撞和连接检查限于当前单体生成器的确定性结构规则；不提前建设 Phase 3 的模块连接/替换系统。

## 非目标

- 不实现城镇规划、模块拖放、任意模块连接图、对象历史、AI Agent 或 Blender 自动渲染。
- 不尝试宣称真实古建营造尺寸；参数是可编辑的方块尺度，不等同于经过文献或实测验证的营造法式。
- 不写入 Minecraft 存档；输出仅为工程和独立 `.schem` 文件。

## 约束与坐标

- Minecraft Java 1.21.5，DataVersion 4325；沿用当前 `BlockState`、`BoundingBox`、`VoxelModel` 和 Sponge v3 读写实现。
- X 为厅堂开间方向，Y 向上，Z 为进深方向；厅堂正面位于较大的 Z 侧，屋脊沿 X 延伸。
- 厅堂开间数为不小于 3 的奇数，使入口保持居中；进深为不小于 5 的奇数，屋脊有唯一中心排。
- 屋顶起坡不超过半进深，以便每一排的台阶高度最多变化一格，避免由参数本身制造空洞。
- 生成器使用固定循环顺序和整数参数；同参数、同材料产生相同坐标到方块状态映射。

## 用户模板参考

- `Template/芳堂-茯茯角.litematic`：单区域尺寸为 43×36×42，7,930 个非空气方块，palette 有 123 个状态；`Template/流苏坊框架-茯茯角.litematic`：31×31×32，3,909 个非空气方块，palette 有 84 个状态。两份文件的 Minecraft DataVersion 都是 3465，低于项目目标 4325。
- 从模板 palette 参考到的可用材料/状态包括 stripped spruce log、spruce planks、stone/deepslate stairs and slabs、fences、glass panes、trapdoors 和 stone walls。Phase 2 用它们作为材料和构件类型的参考，不照搬固定外形、坐标或尺寸，也不将旧 Litematic 原样当作 1.21.5 输出。
- 模板出现 white concrete powder；厅堂门洞上方可能形成悬空墙体，因此默认结构墙使用不会因重力下落的实心方块（如 calcite），不把粉末混凝土用作默认墙材。

## 考虑过的实现方式

1. **只扩写单体厅堂函数**：上线最快，但柱、梁、墙、屋面不能独立复用，不利于后续亭子、门楼和回廊。
2. **先做 JSON 模板/规则引擎**：数据驱动更灵活，但当前没有稳定的构件定义和规则语义，容易把 Phase 2 复杂度提前变成模板语言。
3. **可组合的构件函数 + 参数化装配器**：先以小型纯函数生成局部 `VoxelModel`，再由厅堂和直廊组合。此方案贴合现有核心接口，可直接做三开间/五开间验收，也为 Phase 3 锚点与模块复用留下清晰边界。

## 采用方案

采用方案 3。实现 `generators/components.py` 中的几何/开口原语、`generators/hall.py` 中的 `HallParameters` 与厅堂装配、以及可复用这些原语的直廊配置与生成器。CLI 只增加 `building.type = "hall"` 路由，旧 `simple_house` 格式保持兼容。材料配置是名称到 Minecraft 方块状态字符串的映射；未知材料角色、无效尺寸或语法不合法的状态在生成前明确报错。

Phase 2 沿用当前 `BlockState` 语法解析，并约束生成器自己创建的门、楼梯、玻璃板连接和木梁轴向属性；不建设覆盖 Minecraft 1.21.5 全部方块的版本化状态注册表，也不声称可判定任意自定义状态在游戏内有效。

## 验收

- 构件单测检查坐标、尺寸、空洞、方块状态及非法输入。
- 三开间、五开间厅堂均有连续台基、成列柱、相连梁、居中双格门洞、窗和对称起坡屋顶；屋顶参数不得留下结构性缺排。
- 同一组参数的两个模型完全相等；变更开间数或柱高能相应改变边界和构件坐标。
- 直廊按指定长度和宽度生成重复柱列与连续檐顶。
- CLI 从工程 JSON 生成 Sponge v3 `.schem`，再用现有读取器回读，尺寸和方块数一致。

## 留给实现者的决定

- 本阶段楼梯屋面仅表达离散的对称双坡剖面；瓦作细节、斗拱/榫卯、屋角翘起和风格知识留待后续知识库/构件扩展。
- 直廊采用直线单段，端点及转角连接锚点留待 Phase 3。
- **范围裁定：**版本化的 Minecraft 方块状态注册表超出 Phase 2 范围；本阶段只验证语法和本生成器所创建的已知状态。
